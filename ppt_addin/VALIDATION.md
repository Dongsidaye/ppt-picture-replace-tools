# PowerPoint 3.0.2 验证记录

2026-11-09，Windows x64，PowerPoint 16.0。真实用户文稿仅用于本地只读验证，不随仓库或发布包分发。

- 复现：第 6 页四个不同对象（两个户型、对勾、叉号）在旧缓存中被归成同组，对勾显示成户型图；修复后四者各自归组。该页六张预览已逐一与原生对象导出对照。
- 同源身份来自自有 PPTX 快照的原始媒体 SHA-256，按 SlideID/Shape.Id 和母版/版式关系映射；不使用图片名、媒体顺序或灰度近似作为身份。
- 预览从同一快照的原图及裁剪/翻转/旋转生成。未能确认身份的图片单独列出；不支持的媒体可使用原生对象预览，但不授权自动合组。
- 旧缓存升级为 schema 4；内存和磁盘命中均核对实际对象、源身份及组内关系。原生换图后会重新核对媒体，批量替换前再次验证。
- `group-identity.test.js` 覆盖纯红/纯蓝灰度碰撞、旧元数据污染、未知身份和裁剪窗口；原实现确实失败，修复后通过。
- `source-manifest.test.py` 编译真实 C# 5 读取器，验证关系映射、媒体 SHA-256、路径穿越、外链、DTD、重复 ID、SVG 替代引用、单图 32 MiB 和总展开 256 MiB 限制。
- 导出路由中的斜杠不再污染任务窗格 URL；文件夹/图片/PS 文件选择改为异步调用，取消和文稿切换会释放状态。
- 智能缩放默认等比：30%、20%、10% 的测试文字保持逐行内容一致；20% 表格标题/正文为 4.8pt/2.4pt。超出 1pt 宿主下限会在改动前拒绝。

### 3.0.2 对抗审查

| 缺陷/触发 | 最坏后果 | 防护 |
|---|---|---|
| 不同颜色或不同细节的图具有相同灰度小图哈希 | 合并成错误批量替换目标；普通图片即可触发 | 仅原始媒体 SHA-256 相等且裁剪兼容可合组 |
| 原生换图、幻灯片重排或旧缓存混组 | 缩略图和操作对象错位 | 重算当前 owner key、对象 ID、媒体身份；缓存组关系复核 |
| 读取快照期间切换文稿或重载插件 | 旧结果配给新文稿、无限等待 | COM 文稿身份和引擎代次校验；请求结束与超时保护 |
| 复制失败或剪贴板被外部程序改写 | 上一张图冒充当前图 | 图片清单原图读取及预览不再使用剪贴板 |

相同视觉内容若以不同原始字节重新编码，可能保守分成两组。无法验证的外链、扩展替代图和超限媒体不会自动合组。复杂文稿的全部功能视觉验收仍需用户确认。

## 3.0.0 历史验证

2026-11-06，Windows x64，Microsoft PowerPoint 16.0.20326.20232。测试使用自行创建的演示文稿和图像，不改写用户设计文件。

## 已验证

- 原生 COM 加载、真实 CustomTaskPane 和 WebView2 引擎初始化成功；文稿窗口间迁移与关闭后再打开通过。修复本插件既存的 Office Click-to-Run 注册覆盖值后，冷启动自动加载通过，无需手动设置 Connect。
- 48 个 Ribbon 命令、24 个图标控件映射及 19 个图像资源完整，Office Ribbon 尺寸值合法。
- `adapter.test.js` 与 `port-regressions.test.js` 全部通过；后者包含 9 组状态、文件所有权和失败回滚检查。
- `RunSelfTest` 在真实 PowerPoint 中 18 项通过、0 项失败。可执行测试位于 `tests/selftest.js`。

| 实机范围 | 结果 |

| 类型筛选、对象批量隐藏/显示、锁定/解锁 | 通过；原生 WindowSelectionChange 事件取消锁定对象选择 |
| 智能缩放、恢复、旧会话回调 | 通过；旧回调不修改新选区 |

| 大小写/整词文字替换、样式、颜色、统一大小 | 通过 |
| 包含隐藏对象的页面清理 | 保留内容页 |
| 文件/剪贴板单替与批替 | 保留裁剪与几何；仅替换 2 张匹配图；不同底色图不误命中；输入文件仍存在 |
| 图片清单、缓存、正文定位 | 缩略图可实际解码；第二次命中缓存；选中幻灯片中的目标图 |

## 对抗式审查与修正

| 问题 | 触发方式 / 可复现手段 | 最坏后果 | 修正与验证 |
|---|---|---|---|
| 二进制 COM 字符串在空字节处截断 | 读取普通 PNG 即可触发；原导出数据仅剩 8 字节 | 不同图片同签名，错误批量替换 | 改为 Base64 边界；逐字节实测及不同颜色批替通过 |
| 批量替换误删用户输入文件 | 用系统文件选择器选原图；旧 finally 无条件删除 | 用户图片文件丢失 | 核心替换不删除输入；仅登记的浏览器临时文件由创建者释放；成功/失败/取消均覆盖 |
| 排队操作跨文稿执行 | A 中点击后快速切 B | 修改错误文稿或错误对象 | Ribbon 命令携带窗口身份；UI 二次确认、对象行、PS 作业均绑定文稿 |
| 复制失败使用上一份剪贴板 | Copy 失败后继续 Paste | 误识别、误替换其他图 | Copy 失败终止预览；剪贴板单替捕获裁剪失败时保留原图并回滚新图 |
| PS 裁剪内容重复裁剪 | 已裁剪图片直接 Shape.Export 后载回 | 可见内容再次丢失 | 从 PictureFormat 读取裁剪；裁剪图通过 scratch 导出完整内容；像素级往返通过 |
| 提取页面依赖全局剪贴板 | 连续批替或外部程序改剪贴板 | 提取失败、空目标文稿遗留 | 自有 SaveCopyAs 快照 + InsertFromFile；失败仅清理本次目标和快照 |
| WebView2 异常后复用旧命令 | 页面进程异常、旧异步回调晚到 | 面板失效或旧操作重放 | 引擎代次隔离；丢弃旧队列；下一次显式请求重建。此故障注入尚未做实机验收 |

## 明确边界

- PS 测试拦截外部程序启动，验证的是真实 PowerPoint 导出/载回/撤销。未声称完成 Photoshop 中实际编辑的端到端验收。
- 本机没有可用的 COM 原生对象锁定，使用插件标签、取消选中和位置恢复守卫。不能等同于宿主内核级锁定。
- 本机 x64 已验证；x86 加载器已随包提供，但 32 位 Office 未实机验证。
- 图片清单组合递归、多设计母版和其他继承边界见 [PARITY.md](PARITY.md)。
- 全部按钮逐个点击、复杂文稿压力测试与最终用户视觉验收尚未完成。当前结论是实现覆盖、核心工作流和安装宿主通过，不是任意 Office 版本或任意文稿无故障保证。
