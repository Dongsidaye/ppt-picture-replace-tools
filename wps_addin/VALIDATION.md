# WPS 2.2.0 验证记录

2026-11-11，在本机 WPS 12.1.0.29161 的 JavaScript 加载项中验证 CAD 导入。宿主写入使用自建文稿，原用户文稿单独保留并在安装后恢复打开。

- 7 项完整 WPS 实机流程通过，记录见 `tests/cad-host-validation-2.2.0.json`。覆盖 TEXT / MTEXT 原生可编辑、旋转、真实 OCR 弹窗的启用和跳过、默认不勾选及手动改字、极小 MTEXT 整段 SVG 回退、400 行插入取消、切换文稿回滚及侧栏卸载同步回滚。
- 实机导入请求约 14ms 返回，转换在独立进程执行。导入期间的组件复用已验证，转换、排版和清理阶段未重复弹出外部程序启动提示。转换耗时随图纸内容变化。
- 原有 `mock_e2e.js` 263 项回归通过。新增 engine 10 项、导入面板 10 项、OCR 交互 4 项和文字拟合 10 项 Node 测试通过。
- Worker 7 组可执行测试通过，覆盖真实 DWG 与原文件不变、中文及字体测量、SVG 回退、OCR 修正和裁剪、阶段/索引/哈希/路径边界、TEMP 短路径别名、锁交接及取消清理。Server 7 组可执行测试通过，包含挂起启动、队列串行、心跳、重复完成抑制和成功清理确认竞态。
- WPS 的平面艺术字需要显式 `TextFrame2.WarpFormat = 36`。实测缩宽到 80% 后，字形像素宽约为原来的 80.4%，高度保持。普通文字的 `TextFrame2.WordWrap` 及部分边距 setter 会静默失效，已通过旧 `TextFrame` 设置并读回确认。
- 原生组的独立导出图已目视核对。OCR 选中区域替换为纯黑可编辑文字，未选轮廓保留，文字行距与旋转保持。保存的 PPTX 含 SVG 媒体与原生可编辑文字。

## 对抗审查

| 触发场景 | 最坏后果 | 防护与验证 |
|---|---|---|
| 分批插入时关闭或重载侧栏 | 部分文字残留 | 任务持有本次对象，卸载事件同步回滚；Node 与实机验证 |
| 切换文稿、关闭后重开同名文件 | 旧回调写入另一份文稿 | 捕获原文稿及窗口、关闭事件失效、每批复核；实机换稿回滚 |
| 无效插入 JSON 或原生 setter 静默失败 | 忙状态卡住或错误文字排版 | 修改状态前解析选项，关键属性读回，整段 SVG 回退 |
| 上一阶段释放锁与下一阶段启动重叠 | 长时间等待无结果 | 有界锁重试及独立阶段终态；可执行并发测试 |
| Server 子进程启动失败或组件异常退出 | 反复启动或遗留 OCR 子进程 | 先挂起创建并加入 JobObject，再恢复；失败终态与启动抑制、240s 外层限时 |
| 两个二进制版本共存 | 心跳争抢及重复提示 | 心跳和队列标记绑定 worker SHA-256，同时核对 exe 路径 |
| 前端先确认清理结果，Server 后检查退出 | 成功操作被重写为错误 | cleanup 的成功退出允许状态已被确认删除；确定性竞态测试 |
| OCR 重叠框、非法坐标或误判图形 | 错误裁剪或文字内容错误 | 500 项上限、唯一索引和有限边界校验，默认不勾选并支持改字，顺序裁剪区域并集 |

OCR 可能误字、拆行或识别到图形，需要核对内容和蓝框。选中范围内的其他线条也会被替换。小于 1pt 或无法可靠拟合的原有文字保留 SVG。布局空间、外部栅格图片和 OLE 对象暂未导入。

本地组件在空闲 60 分钟后退出。Windows 重启或组件退出后再次使用时，WPS 可能询问是否启动随包组件。Server 刚退出但心跳尚在有效期内时，首次请求可能提示组件未启动，需要重新选择文件。复杂工程 DWG、极长行及其他 WPS 版本仍需实际文件验收。
